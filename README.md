# Owlett - an AI agent for birding

[简体中文](README.md) | [English](README.en.md) | [全部说明文档](docs/INDEX.md)

**把观鸟计划、现场鸟鸣识别与事后回顾串起来的 Android AI 助手。**

Owlett 帮你在出发前整理鸟况和目标，在野外录下鸟声并进行实时本地识别，回来后回听片段、关联行程和整理观察结果。你可以直接操作录音与计划页面，也可以用自然语言让助手调用应用内工具。

本项目提供 Android 客户端与可选的精准识别后端源码。支持 **Android 8.0 及以上**；界面以中文为主。版本信息见 [version.properties](version.properties)，变更见 [更新记录](CHANGELOG.md)。

## 能用它做什么

| 场景 | Owlett 的功能 |
| --- | --- |
| 出发前做准备 | 创建观鸟计划，查询 eBird 鸟况，整理目标鸟种清单。 |
| 现场录下鸟声 | 录音、暂停与恢复；Release APK 内置模型，在手机上实时识别并保存结果。 |
| 回来仔细听 | 在频谱中浏览录音，选择时间片段或频率区域，回听并分享选区。 |
| 整理一次观鸟 | 把录音行程关联到计划，整理目标完成情况，按已有识别记录筛选鸟鸣片段。 |
| 查资料、听鸣声 | 查询鸟种资料；配置 xeno-canto 后搜索和播放参考鸣声。完整本地图鉴需要额外资源。 |
| 对选区进一步识别 | 把选定音频提交到自己部署的后端，使用 BirdNET 2.4 或 Perch v2。 |

录音、计划、识别结果与聊天保存在本机。实时识别使用手机上的模型；AI 对话、在线鸟况、参考鸣声与后端识别需要网络和对应配置。

## 和助手一起完成任务

在设置中配置 DeepSeek API 后，可以直接向 鸮老师 描述需求：

> 创建一个周六上午的观鸟计划，地点是天津洒金沱魔术林。
>
> 把今天上午的录音行程关联到这个计划。
>
> 整理这个行程里大杜鹃置信度大于 30% 的叫声。

也可以在输入框输入 `/` 选择场景：

| 命令 | 用途 | 命令 | 用途 |
| --- | --- | --- | --- |
| `/plan` | 管理计划 | `/activity` | 整理鸟况 |
| `/targets` | 调整目标清单 | `/bird` | 查询鸟种资料 |
| `/calls` | 查询参考鸣声 | `/link` | 关联录音行程 |
| `/clips` | 整理录音片段 | `/settle` | 行程结算 |
| `/settings` | 修改普通设置 | | |

修改数据前默认展示预览并请求确认；地点或行程不明确时会要求补充信息。助手整理录音片段时使用已有识别记录，不会重新识别音频。实际回答和工具选择取决于所配置的模型，识别结果也需要结合现场观察判断。

工具的实现与权限范围见 [助手工具与场景技能](docs/OWLETT_TOOLS.md)。

## 安装与配置 API

**以下安装流程面向一般用户**。对于潜在的开发需求，请参见 [从源码运行](docs/RUN_FROM_SOURCE.md)。

### 安装 Owlett

**Release APK 下载：[v1.0.6](https://github.com/greatwyj1/Owlett/releases/tag/v1.0.6)。**
<!-- 发布后在此填写已核实、内置本地鸟鸣识别模型的正式 APK 下载链接。 -->

正式安装包发布后，在 Android 8.0 及以上手机上下载 APK，点击文件并按系统提示完成安装；如果系统询问，允许当前浏览器或文件管理器安装应用。

**安装内置模型的 Release APK 后，可立即使用本地鸟鸣识别功能，无需配置 API。** 在“录音”页点击开始，首次使用时授予麦克风权限即可。上述说明面向正式安装包；自行编译的无模型调试包不具备该能力。

AI 助手、鸟况分析与 AI 制定观鸟计划、在线鸣声播放、后端精准识别均需要额外配置服务才能使用。请参考下述流程，按需配置。手动创建本地计划、回听自己的录音无需配置这些 API。

| 想使用的功能 | 需要配置 |
| --- | --- |
| 与 AI 助手对话、通过对话制定或整理计划 | DeepSeek |
| 查询在线鸟况、根据 eBird 数据分析计划 | eBird；通过助手操作时还需 DeepSeek |
| 让助手搜索并播放参考鸟鸣 | DeepSeek + xeno-canto |
| 把音频片段交给电脑上的另一模型复核 | 自部署精准识别后端，不需要 DeepSeek |

API Key 是服务提供给你的访问密钥。请分别填入对应设置页面，不要把密钥发到聊天框中。

### 1. DeepSeek：AI 助手与对话式计划

**使用场景：** 在“Owlett 助手”中提问鸟类知识，附加计划或行程，让助手创建计划、调整目标或整理录音。例如：“帮我创建周六上午的观鸟计划”。如果希望助手结合在线鸟况提出建议，还需完成下一节的 eBird 配置。

**获取密钥：**

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录账号。
2. 进入 [API keys 页面](https://platform.deepseek.com/api_keys)，创建一个 API Key 并复制保存。这里需要的是开放平台的 API Key。
3. 在平台确认 API 账户有可用额度；API 调用按平台规则计费，详见 [官方 API 说明](https://api-docs.deepseek.com/zh-cn/) 和 [模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。

**在 Owlett 中配置：**

1. 打开 **设置 → DeepSeek**，将密钥粘贴到“DeepSeek API 密钥”输入框，点击“保存”。
2. 点击“测试”，确认连接成功，再从“模型”列表中选择可用模型。连接测试只查询模型列表，不代表已完成一次 AI 回答。
3. 回到助手发送一条简单问题，确认可以收到回答。要让助手主动调用工具，可在设置中开启“自动使用技能”；也可以输入 `/` 手动选择场景。

如果测试失败，先核对密钥和网络；如果测试成功但对话失败，再检查账户额度、所选模型和页面错误提示。

### 2. eBird：在线鸟况与计划分析

**使用场景：** 在“计划与行程”中准备出行时，查询地区和鸟点的观察记录，分析鸟况并整理目标清单；也可以在助手中提出鸟况查询。eBird 提供观察数据，DeepSeek 负责对话及工具调用，两者使用不同的密钥。

**获取密钥：**

1. 打开 [eBird API Key 申请页](https://ebird.org/api/keygen)，注册或登录自己的 Cornell Lab / eBird 账号。
2. 按页面提示完成申请并复制个人 API Key。如果直接入口不可用，可从 [eBird 数据下载页](https://ebird.org/data/download) 找到 API 申请入口。
3. 这是 API 访问密钥，无需为使用 Owlett 下载整套鸟类观察数据。申请入口与用途可核对 [eBird 官方数据说明](https://support.ebird.org/en/support/solutions/articles/48000838205-download-ebird-data)。

**在 Owlett 中配置：**

1. 打开 **设置 → eBird**，把密钥填入“eBird 密钥”，点击“保存”。
2. 点击“测试连接”，确认显示“已连接 eBird”。
3. 回到“计划与行程”选择地区、鸟点和日期，再查询或分析鸟况；使用助手完成这些操作时，先配置 DeepSeek。

没有记录不一定是配置失败，也可能是所选地点或日期缺少数据。请结合结果中的地点、时间和来源判断。

### 3. xeno-canto：搜索与播放参考鸟鸣

**使用场景：** 想听某种鸟的典型叫声、与现场听到的声音比较时，在助手中输入 `/calls` 或提出“找一些中国地区的乌鸫鸣声”。结果卡可播放、暂停和拖动进度，并保留原始录音来源。此处指在线参考鸟鸣，自己的录音回放不需要这个服务。

**获取密钥：**

1. 打开 [xeno-canto](https://xeno-canto.org/)，注册并登录账号，按网站提示完成账号验证。
2. 进入 [个人账户页面](https://xeno-canto.org/account)，查找并复制 API Key。Owlett 使用 API v3；如果页面暂未显示密钥，请按账户页面及 [官方 API 说明](https://xeno-canto.org/explore/api) 的提示操作。

**在 Owlett 中配置：**

1. 打开 **设置 → xeno-canto**，粘贴 API 密钥，点击“保存”，再点击“测试”。
2. 配置 DeepSeek 后回到助手，指定鸟种及国家或地区发起鸣声查询。
3. 在结果卡中点击播放。首次播放需要联网加载；已经加载的部分会缓存，缓存可在 xeno-canto 设置中清空。

查不到结果时可换一个鸟种或地区，不必立即更换密钥。网页如提示浏览器验证，请在普通浏览器中完成登录和密钥获取。

### 4. 后端精准识别：让电脑上的另一模型再听一次

**使用场景：** 部分情况下，手机本地模型可能无法识别鸟鸣。如果你在自己的电脑上配置了后端识别功能，就可在 App 中将待识别的音频片段传输到运行后端服务的电脑上，使用另外的模型进行更精确的二次识别。例如，手机上的 BirdNET 未能命中时，可尝试电脑上的 **Perch v2**；后端也支持 **BirdNET 2.4**。二次识别提供另一份判断，不保证每次都更准确。

**后端识别服务 Release 代码压缩包下载：[v1.0.6](https://github.com/greatwyj1/Owlett/releases/tag/v1.0.6)。**
<!-- 发布后在此填写后端独立源码 ZIP 下载链接；包需保留部署指南引用的 tools/release 与 resources 相对目录。 -->

这项功能不需要向 DeepSeek、eBird 或 xeno-canto 申请 API。你需要一台能运行 Python 3.11 的电脑，并自己设置服务访问令牌。手机提交识别时，电脑须开机、保持服务运行且能被手机访问；电脑不在身边时，也可以先保存录音，回到同一网络后再提交。

**在电脑上准备：**

1. 下载并解压后端代码包，按 [后端配置指南](server/precise_recognition/DEPLOYMENT.md) 创建 Python 3.11 环境、安装依赖。
2. 使用标注“内置模型”的后端ZIP时，无需另下模型，按包内README校验并测试；只下载源码时仍需准备模型。建议先验证 Perch v2，以获得与手机本地模型不同的识别结果；也可以选择 BirdNET 2.4。
3. 设置自己的 `API_TOKEN`，让服务监听电脑的局域网地址和 `8000` 端口。保持终端运行，让手机与电脑连接同一可信 Wi-Fi。完整命令、系统差异和重启方法均在上述指南中。

**在 Owlett 中配置：**

打开 **设置 → 精准识别**，填写下列项目；此页修改会自动保存。

| 页面字段 | 填写方式 |
| --- | --- |
| 服务地址 | 完整识别接口，例如 `http://0.0.0.0:8000/api/v1/precise-recognition`；将示例 IP 换成电脑实际地址。 |
| 访问令牌 | 与电脑设置的 `API_TOKEN` 完全相同。 |
| 声学模型 | 选择已在电脑上检查通过的 Perch v2 或 BirdNET 2.4。 |

暂停录音或打开已保存行程，在频谱中选择一段 **不超过 15 秒** 的音频，点击“精准识别”，核对发送目标后提交。选择频率区域时，提交的是带通滤波后的片段；不会上传整段行程。

如果连接不上，核对电脑 IP、服务是否运行以及防火墙设置；手机不能用 `127.0.0.1` 访问电脑。提示 `401` 时检查访问令牌。跨公网使用需要 HTTPS 等额外部署，见 [后端配置指南](server/precise_recognition/DEPLOYMENT.md)。

## 第一次使用

1. 进入“录音”页，点击开始并授予麦克风权限。使用内置模型的 Release APK 时，可同时查看实时识别结果。
2. 暂停录音，选择时间窗或频谱区域进行回听；结束后到“计划与行程”查看保存的行程。
3. 创建观鸟计划，按需要添加目标鸟种，并关联已完成的录音行程。
4. 配置 DeepSeek 后，在助手中附加计划或行程，让它帮助整理结果；每条消息最多添加一个附件。

更详细的操作、音频分享、数据导入导出与常见问题见 [中文使用说明](USER_GUIDE.md)。

## 数据与许可

本地实时识别无需上传录音。使用联网功能时，对话及必要的工具摘要会发送给配置的 AI 服务，鸟况与鸣声查询会访问对应数据源；主动提交精准识别时，所选音频及相关参数会发送到配置的后端。完整的数据流与存储说明见 [隐私说明](PRIVACY.md)。
