# Owlett 两层工具与场景技能

[简体中文](OWLETT_TOOLS.md) | [English](OWLETT_TOOLS.en.md)

## 使用方式

用户菜单只展示九个场景：计划管理、整理鸟况、目标清单、鸟种资料、鸣声、关联行程、整理录音、行程结算、普通设置。对应命令为 `/plan /activity /targets /bird /calls /link /clips /settle /settings`。

自动技能开启时，模型可以直接组合通用工具，也可读取打包的场景说明。关闭自动技能后，普通对话不提供工具；手动选择场景仅开放该场景的工具范围。每轮配置包含模型、提示词、自动化权限和技能说明快照，重试不受之后的设置变化影响。

可以尝试：“把两个计划的日期都改为9月15日”“关联上午的录音，然后结算”“比较鸟况后保留我指定的目标”“找出可信度大于30%的片段并播放”“将外观改为深色”。这些组合任务仍需真实模型验收，不把本地测试当成模型行为保证。

## 边界

- 参数由应用校验；工具不能修改密钥、服务地址、助手权限或系统提示词，不能执行代码、任意SQL、文件访问、永久删除录音或上传录音。
- 默认修改前预览。自动模式跳过普通写入确认，不能跳过地点消歧和必要信息。批量修改在一个事务中提交，版本变化后旧预览失效；收据防止同一操作重试造成重复写入。
- 单轮最多24次工具调用，相同失败连续3次停止。已完成步骤保留，失败不代表之前步骤回滚；确认卡和结果卡可跨会话切换保留。
- 网页及工具输出是资料，不是新指令。只发送必要摘要，不发送本地路径、密钥或完整网页；隐藏 reasoning 仅供合法的工具协议上下文。
- 计划删除移入30天回收站，恢复保留关联；到期只清理计划，不删除录音。旧待确认卡升级后需要重新准备。

## 开发位置与验证

`OwlettToolExecutor` 负责统一检查；`OwlettBusinessTools` 连接现有业务；`OwlettSceneSkills` 注册场景；`app/src/main/resources/owlett/skills` 保存版本化说明。两库均为v4，新增字段兼容读取。

当前版本验证结果见[更新记录](../CHANGELOG.md)。设备测试编译不等于已执行设备测试；真实DeepSeek组合任务、键盘及窄屏行为仍需手机验证。公开版本只注册eBird数据源。

九份场景说明的双语阅读版见 [文档索引](INDEX.md)；应用实际使用的提示词文件保持不变。
